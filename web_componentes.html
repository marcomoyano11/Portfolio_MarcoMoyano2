Comic Shop componentes

componentes web

En este ejercicio, tuvimos que realizar un paquete de componentes web, yo decidí enfocar el proyecto en una tienda de comics online, creando header, enlaces, botones, cards etc. Los componentes fueron realizados en figma y posteriormente traducidos a código HTML y CSS. La paleta de colores, la tipografía y los elementos gráficos siguen un estilo cartoon llamativo y desenfadado, pero a la vez sencillo y fundional.

Created by Marco Moyano.
